# `.forge`

This directory contains the FORGE system.

FORGE is the reusable intelligence, workflow, policy, context, and verification layer used by an AI agent while developing a product.

## Structure

- `core/` — shared orchestration contracts and mechanisms
- `intelligence/` — modular reasoning domains
- `workflows/` — development lifecycle procedures and exit conditions
- `policies/` — non-negotiable framework guardrails
- `verification/` — objective and human quality gates
- `adapters/` — agent/environment integration guidance
- `templates/` — project artifacts FORGE may generate
- `context/` — project-specific living context
- `decisions/` — recorded product and technical decisions
- `state.md` — current project state
- `docs/` — FORGE system documentation

Project context is expected to evolve. Core FORGE rules are not to be weakened to bypass a quality gate.

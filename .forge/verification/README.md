# Verification

Verification turns FORGE principles into evidence.

Depending on the project and task, checks may include:

- formatting, linting, and type checking
- unit, integration, and end-to-end tests
- production build validation
- dependency and security checks
- accessibility and responsive checks
- visual verification for user-facing changes
- deployment and environment validation

A check is required when its failure could materially affect correctness, security, user experience, or production readiness.
